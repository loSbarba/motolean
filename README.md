# Sito web MotoLean

Sito statico (solo HTML, CSS e un piccolo script), nessuna compilazione.

- `index.html`, `privacy.html`, `termini.html`, `elimina-account.html`: italiano
- `en/`: inglese (`index.html`, `privacy.html`, `terms.html`, `delete-account.html`)
- `style.css`, `gauge.js` (indicatore di piega animato), `img/`

Da completare prima della pubblicazione:
- testi legali: bozze da /mnt/project-files/legale/ (da far rivedere), segnaposto [Nome e cognome], [città], [data];
- email di contatto (`[email di contatto]` / `[contact email]`);
- link agli store al posto dei pulsanti "Presto".

Per vederlo in locale basta aprire `index.html` nel browser.
